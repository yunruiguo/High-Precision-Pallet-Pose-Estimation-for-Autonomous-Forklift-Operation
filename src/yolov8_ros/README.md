# YOLOv8 Pallet Pose ROS 2 Packages

This folder contains the ROS 2 packages for pallet-part detection and pallet
pose estimation.

For installation, launch commands, topic interfaces, algorithm notes, and
YOLOv8 references, see the workspace README:

```text
../../README.md
```

## Packages

- `yolov8_ros`: Python nodes.
- `yolov8_msgs`: custom detection messages.
- `yolov8_bringup`: launch files.
